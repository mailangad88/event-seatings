# Writing copy for this site

All visible text (pages, headings, buttons, FAQs, blog posts, data files, alt text, emails, kits) must read like a plain-spoken local business. No jargon and no AI-sounding phrases ("Real humans", "seamless", "elevate", "curated", "vetted vendors", "X, not Y" slogans, "One list. One quote." fragments). Follow `docs/plain-writing-rules.md` and run `node scripts/check-copy.mjs` before opening a PR; CI fails on banned phrases.
