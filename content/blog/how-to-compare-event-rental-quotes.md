**Quick answer**

Put every quote on the same basis: same items, same quantities, same dates, and the same services (delivery, setup, pickup, waiver, tax). Then compare the all-in total, plus the policies on changes, cancellation and breakage. The lowest unit price is rarely the lowest total once services are added.

</div>

Three companies, three PDFs, three totals that do not line up. Planners in Chicago hit this wall every season because quotes are not standardized. One company bundles delivery and setup into the chair rate. Another quotes bare chairs and adds the rest later. Comparing them directly is like comparing a flight price with and without bags.

## Step 1: Build one master list

Before you request anything else, write a single list of what you need. Use the same list for every company so the quotes can be matched.

<ol class="flow">
<li><strong>Dates and times:</strong> delivery window, event hours, pickup window.</li>
<li><strong>Address:</strong> venue name, floor, loading dock or elevator notes.</li>
<li><strong>Items and quantities:</strong> chairs, tables, linens, place settings, extras.</li>
<li><strong>Services:</strong> setup to a layout, breakdown, will-call or delivered.</li>
<li><strong>Extras:</strong> waiver, spares, rush or after-hours handling.</li>
</ol>

If you are unsure of quantities, start with our guide to [how many chairs you need](/blog/how-many-chairs-do-i-need).

## Step 2: Normalize each quote

Open a spreadsheet with one column per company and these rows. Fill in a number, a "no," or "ask."

<div class="table-wrap">

| Row | Company A | Company B | Company C |
|---|---|---|---|
| Items subtotal | | | |
| Delivery and pickup | | | |
| Setup | | | |
| Breakdown | | | |
| Damage waiver | | | |
| Tax | | | |
| All-in total | | | |
| Change deadline | | | |
| Cancellation terms | | | |

</div>

When a cell is blank in a quote, that service is either included or missing. Email them: "Is setup included in this price?" A yes is good. A no goes in the cell as a dollar figure you request.

## Compare the policies, not just the price

Two quotes at the same total can be very different risks. Put these side by side:

- **Cancellation and date changes.** Is the deposit refundable? Can you move the date? Our guide to [cancellation and date-change policies](/blog/event-rental-cancellation-and-date-change-policy) shows what to look for.
- **Headcount flexibility.** Until when can you lower the count, and by how much? See [final headcount deadlines](/blog/final-headcount-deadline-event-rentals).
- **Damage and loss.** What is covered and what is billed after the event?
- **Delivery windows.** Wide windows are hard to plan around at Chicago venues with scheduled dock times.
- **Quality of the product.** A cheaper chair that arrives scuffed costs you in photos. Ask for photos of the actual stock.

Some less obvious differences:

- **Minimums.** A company may have a minimum order or delivery minimum that kicks in for small events.
- **Substitutions.** If a chair style runs out, can they swap in a different one, and will you approve it?
- **Spares.** A cushion of extra chairs for a late headcount may be included or billed.
- **Pickup timing.** Next-day pickup versus same-night pickup changes the cost and your venue's rules.

## Scoring the finalists

Once totals are normalized, add a simple score. Give each company 1 to 5 on responsiveness, product quality, flexibility and clarity. A company that answered your email in an hour with clear numbers is telling you how the event week will feel. Slow, vague answers now tend to turn into slow, vague answers on delivery day.

## Don't ask for a lower price before you ask for a clearer one

Negotiating on an unclear quote wastes time. First get clarity on what is included, then ask if there is room to adjust. Our tips on [how to save on event rentals](/blog/how-to-save-money-on-event-rentals) cover where there usually is flexibility, like off-peak days and simpler layouts.

## Frequently asked questions

### How many rental quotes should I get?

Two or three is enough for most events. More than that creates confusion without new information. Make sure each quote uses the same item list and dates.

### Should I pick the cheapest rental quote?

Not automatically. Compare the all-in total and the policies. A slightly higher quote that includes setup and flexible changes can be the better value, and a very low quote can signal missing services.

### What should I do if a quote doesn't list delivery?

Ask directly whether delivery, setup and pickup are included and, if not, request those as separate lines. An unlisted fee on the invoice is worse than a high number on the quote.

### Can I use one company's quote to negotiate with another?

You can say you have another quote and ask whether they can match the services, but do it politely and with the same item list. Many companies will not change rates, though they may adjust services or delivery timing.

### How do I compare a package to an a la carte quote?

Break the package into its pieces and price each one. If the package includes items you do not need, it may not be a deal. If it includes services you would pay for anyway, it often is.

### Do I need a written quote to compare properly?

Yes. A phone number or text message is not enough because you cannot see which services are included. Ask for an itemized quote by email.
